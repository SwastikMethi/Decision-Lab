# decisionlab-mcp MCP server

Generated by generate-mcp. Local stdio MCP server that exposes curated operations of the target API as tools. Design and exclusions: `../mcp-output/MCP_DESIGN.md`. Test results: `../mcp-output/TEST_REPORT.md`.

## Run

```
uv run --directory mcp-server repo-mcp
```

Claude Code and Codex start it from `.mcp.json` and `.codex/config.toml` at the repository root.

## Environment

| Variable | Required | Default | Purpose |
| --- | --- | --- | --- |
| TARGET_API_BASE_URL | yes | – | Base URL of the API, http or https only |
| TARGET_API_TOKEN | if the API needs auth | – | Sent as `Authorization: Bearer <token>` |
| TARGET_API_TIMEOUT_SECONDS | no | 15 | Per-request timeout |
| MAX_RESPONSE_BYTES | no | 262144 | Responses above this size are rejected |

Never commit a real value. `.env.example` holds placeholders only.

## Layout

| File | Owner | Purpose |
| --- | --- | --- |
| `src/repo_mcp/server.py` | generate-mcp | MCPServer instance, `main()` |
| `src/repo_mcp/tools.py` | generate-mcp | curated tools, regenerated each run |
| `src/repo_mcp/custom_tools.py` | you | hand-written tools, never overwritten |
| `src/repo_mcp/api_client.py` | generate-mcp | HTTP calls, SSRF block, redaction, size and time limits |
| `src/repo_mcp/config.py` | generate-mcp | environment settings |
| `tests/` | generate-mcp + you | respx-mocked tests; `test_tools.py` is regenerated |

## Test

```
uv run --directory mcp-server pytest -q
npx -y @modelcontextprotocol/inspector --cli uv run --directory mcp-server repo-mcp -- --method tools/list --format json
```
